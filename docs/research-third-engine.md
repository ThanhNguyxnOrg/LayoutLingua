# Đặc tả engine thứ 3 (primary sources)

> Nền hiện có: `GoogleTranslator` GET `translate.google.com/m` + `HandoffTranslator` table-lookup (`pdf2zh/translator.py`); mọi output qua `validate_formula_placeholders`/`validate_style_tags`; đã có `RateLimiter` + circuit-breaker dùng chung. Không sửa code ở đây.

## 1. DeepLX free — protocol đủ để implement `DeepLXTranslator(BaseTranslator)`

- Method/path: `POST {DEEPLX_ENDPOINT}/translate`, `Content-Type: application/json`; mặc định self-host `http://localhost:1188/translate`, port `1188` (`service/config.go:Router`, `main.go`, README `curl .../translate`). Nguồn: https://github.com/OwO-Network/DLX + `service/service.go:Router` + `README.md#Translate`.
- Request JSON (`PayloadFree`): `{"text": str, "source_lang": "EN", "target_lang": "ZH", "tag_handling": "html|xml"?}`; `source_lang=""|"auto"` = autodetect (bỏ field upstream), `target_lang` bắt buộc, khác `"auto"`; key không phân biệt hoa/thường. Nguồn: `service/service.go:PayloadFree` + `translate/translate.go:resolveTargetLang/resolveSourceLang`.
- Response JSON free: `{"code":200, "data": str, "source_lang", "target_lang", "alternatives": null, "id": unix_ms, "method":"Free"|"Pro"}`; lỗi `{"code": 4xx/5xx, "message": ...}` (`400` payload/tag sai, `413` quá dài, `429` IP bị ban, `403` auth/client cũ). Nguồn: `service/service.go:r.POST("/translate")` + `translate/translate.go:TranslateByDLX`.
- Biến thể tương thích official: `POST /v2/translate` nhận `text[]`/`source_lang`/`target_lang` (JSON hoặc form) và trả `{"translations":[{"detected_source_language", "text"}]}`; `POST /v1/translate` như `/translate` nhưng đòi Pro `dl_session` (Bearer OAuth, không phải cookie). Nguồn: `service/service.go:r.POST("/v2/translate")`, `r.POST("/v1/translate")` + https://owo-network-deeplx.mintlify.app/api-reference/official-format.
- `lang_map` gợi ý: target `EN→en-US`, `PT→pt-BR`, `ZH→zh-Hans`, `ZH-HANT→zh-Hant`, `EN-GB/PT-PT/PT-BR/ES-419/FR-CA/DE-CH` giữ nguyên; source `EN→en`, `PT→pt`, `ZH*→zh` (target-only script gửi làm source sẽ bị bỏ qua, lỗi #239); `ZH` nguồn dùng `lang_map {"zh":"ZH","zh-cn":"ZH",...}`. Nguồn: `translate/translate.go:targetLangMap/sourceLangMap`.
- Giới hạn ký tự: `maxFreeTextLength = 1500` rune cho anonymous (`413 "text exceeds maximum length ... anonymous oneshot limit is 1500"`), nên `MAXIMUM_SEGMENT_CHARACTERS = 1500` (không phải 5000 như Google) + giữ `SegmentTooLongError`. Nguồn: `translate/translate.go:maxFreeTextLength/TranslateByDLX`.
- Auth/timeout: self-host `TOKEN` tùy chọn (`?token=` hoặc `Authorization: Bearer <t>`/`DeepL-Auth-Key <t>`, sai → `401`); mặc định rỗng = không auth; upstream anonymous gửi literal `Authorization: None`. Timeout upstream `oneshotTimeout=20s`, warmup cookie `5s` → khuyến nghị `timeout=20–30` (repo Google đang `30` trong `do_translate`), tái dùng `requests.Session` + `_shared_rate_limiter` + `_circuit_*` hiện có. Nguồn: `service/service.go:authMiddleware/config.go:TOKEN` + `translate/translate.go:callOneshot/oneshotTimeout`.
- `tag_handling` chỉ nhận `""|"html"|"xml"` (sai → `400`) nhưng **bị bỏ qua upstream** (oneshot không có tag-handling như official v2) → `<bN></bN>`/`<s1..3>` có thể bị đảo/xóa, bắt buộc giữ `validate_*` + `restore_formula_placeholders`. Nguồn: `service/service.go:tagHandling` + `translate/translate.go:_ = tagHandling`.
- Khác DeepL official: official `https://api-free.deepl.com` / `https://api.deepl.com` + `POST /v2/translate`, auth bắt buộc `Authorization: DeepL-Auth-Key <key>`, quota Free ~500k chars/tháng, request ≤128KiB/header ≤16KiB; DeepLX free là giả iOS client (`oneshot-free.www.deepl.com/v1/translate`, TLS `HelloIOS`, UA `DeepL/x CFNetwork/... Darwin/...`, `x-app-os-version/instance-id/session-id`, `app_information`, version resolve runtime, sai version → `429` toàn IP). Nguồn: https://developers.deepl.com/docs/resources/usage-limits + `openapi.yaml (servers/api.deepl.com, api-free.deepl.com)` + `translate/translate.go:oneshotFreeEndpoint/callOneshot/iosUserAgent`.

## 2. Bing keyless — flow còn hoạt động không

- Flow (`translators/server.py:class Bing`, còn trên `master`): `GET https://www.bing.com/Translator` (hoặc `cn.bing.com`) → `get_ig_iid` parse `IG:"..."` + `//*[@id="tta_outGDCont"]/@data-iid` → `get_tk` parse `var params_AbusePreventionHelper = ...;` + `exejs` (cần Node.js) → `{key, token}` → `POST https://.../ttranslatev3?isVertical=1&IG=..&IID=..` form `{text, fromLang, to, tryFetchingGenderDebiasedTranslations=true, key, token}` → `data[0].translations[0].text`. Nguồn: https://github.com/UlionTse/translators + `translators/server.py:Bing.get_ig_iid/get_tk/bing_api`.
- Giới hạn/refresh: `input_limit = 1000` chars (`check_input_limit`), session refresh mỗi `1000` req/`1500`s, `zh-Hans`/`auto-detect` mặc định. Nguồn: `translators/server.py:Bing.__init__/bing_api`.
- Trạng thái: issues `bing was down #178` (12/2025), `#176/#174` đều đã `closed`, maintainer vẫn giữ engine và xin log để fix — coi là **còn chạy nhưng dễ vỡ**: đổi XPath/HTML, đổi `IG`/`AbusePreventionHelper`, thiếu Node là gãy ngay. Nguồn: https://github.com/UlionTse/translators/issues/178 + `/issues/176`.

## 3. Khuyến nghị: DeepLX trước, Bing dự phòng

- Làm `DeepLXTranslator` trước: khớp interface `name="deeplx"`, `lang_map`, `do_translate`, `MAXIMUM_SEGMENT_CHARACTERS=1500`; đọc `DEEPLX_ENDPOINT` (default `http://localhost:1188/translate`), `POST` JSON trên, parse `data`, map lỗi `429→circuit`, qua `validate_*`, `timeout≈20–30s`.
- Rủi ro DeepLX: phải tự host `:1188` (Docker `ghcr.io/owo-network/deeplx`/`missuo/deeplx`); segment ngắn hơn Google (1500 vs 5000) nên tốn request hơn; QPS cao → `429` ban IP tạm; DeepL đổi oneshot/TLS/app-version là gãy theo; `EN/PT/ZH` phải map đúng bảng trên.
- Rủi ro Bing: không cần host/key/billing nhưng scrape `IG/IID/key/token` mong manh nhất, giới hạn chỉ 1000 chars, thêm dep Node (`exejs`), HTML đổi là gãy toàn bộ — chỉ hợp làm fallback sau DeepLX.
