# Repo giữ công thức hướng tiếng Trung: PDFMathTranslate, BabelDOC và họ hàng

> Ngày: 2026-10-09. Nguồn chính (primary): repo GitHub + source raw + docs chính thức; mỗi mục ghi sở hữu claim. Không sửa code.

**Tóm tắt:** User nhớ đúng — `Byaidu/PDFMathTranslate` (github.com/Byaidu/PDFMathTranslate, 37.4k★) chính là upstream họ `pdf2zh/` trong repo này, mặc định dịch sang tiếng Trung (`-lo zh`), giữ công thức bằng font-TeX/monospace + placeholder `{vN}`. `funstory-ai/BabelDOC` (github.com/funstory-ai/BabelDOC, 9.7k★) là backend mới (`--babeldoc`, `--mode precise`) với pipeline IR, typesetting CJK (kinboku, line-skip 1.5/1.3), glossary CSV + auto-extract, cache 50k + QPS limiter. LayoutLingua hơn ở tiếng Việt/diacritics, 48 ngôn ngữ, refuse-segment-dài, TranslationReport, table 50%; thua ở CJK typesetting, glossary, batching/QPS chuẩn.

## 1. PDFMathTranslate (Byaidu/PDFMathTranslate)

- Giữ công thức: `vflag(font,char)` trong `pdf2zh/converter.py::TranslateConverter.receive_layout` — font LaTeX `(CM[^R]|MS.M|XY|MT|BL|RM|EU|LA|RS|LINE|LCIRCLE|TeX-|rsfs|txsy|wasy|stmary|.*Mono|.*Code|.*Ital|.*Sym|.*Math)` (tuỳ biến qua `-f/-vfont`), ký tự `Lm/Mn/Sk/Sm/Zl/Zp/Zs` + Hy Lạp `0x370-0x400` (`-c/-vchar`); layout `cls==0` (abandon/figure/table/isolate_formula) + subscript `<0.79×` + ma trận dọc; gom vào `vstk/var` → chèn `{vN}` (`{v{id}}`), vẽ lại glyph/line gốc ở phase C. Nguồn: raw `pdf2zh/converter.py` (`vflag`, `receive_layout`), `docs/ADVANCED.md#exceptions` (mẫu `-f/-c` mặc định).
- Placeholder/validate: prompt LLM `Keep the formula notation {v*} unchanged` (`pdf2zh/translator.py::BaseTranslator.prompt`, `docs/ADVANCED.md#prompt`); phía render chỉ `add_cjk_latin_spacing(new)` rồi tách `{vN}` bằng regex — **không có validate cân bằng** như local. Nguồn: raw `translator.py::prompt`, `converter.py` phase C (`vy_regex`), `text_spacing.py::add_cjk_latin_spacing`.
- Hỗ trợ TQ: font `SourceHanSerif{CN,TW,JP,KR}-Regular.ttf` theo `LANG_NAME_MAP` (`pdf2zh/high_level.py::download_remote_fonts`, fallback `babeldoc.assets.get_font_and_metadata`); `LANG_LINEHEIGHT_MAP` zh=1.4/ja=1.1/ko=1.2 (`converter.py` phase C); `add_cjk_latin_spacing` chèn space CJK↔Latin giữ combining-mark (changelog README 2026-10-03 + `text_spacing.py::_script`). Nguồn: raw `high_level.py::download_remote_fonts`, README §2/§4.1, `text_spacing.py`.
- Engine/cache/concurrency: ~24 engine — Google/Bing/DeepL/DeepLX/Ollama/OpenAI/Azure/Gemini/Tencent/Dify/AnythingLLM/Argos/Grok/Groq/DeepSeek/MiniMax/qwen-mt… (`translator.py`, `docs/ADVANCED.md#services`); Google cắt `text[:5000]`, Bing `[:1000]` (**cắt câm**, local thì refuse); cache peewee `~/.cache/pdf2zh/cache.v1.db` **không giới hạn dòng** (`cache.py::TranslationCache`, `init_db`); `ThreadPoolExecutor(max_workers=thread)` từng page, retry vô hạn `wait_fixed(1)`; có `--ultrafast` (pdf-inspector, bỏ ONNX/OCR/subset) và OCR Tesseract (`high_level.py::translate_patch/translate_stream/_ocr_pages`). Nguồn: raw `translator.py` (Google/Bing/OpenAI…), `cache.py`, `high_level.py`, `ADVANCED.md#ultrafast/#cache/#threads`.
- Khác bản bundled local (`D:\Code\LayoutLingua\pdf2zh\`): local thêm `converter.py::vflag` (giữ glyph output-font thiếu, bullet PUA, `So`, descriptor Flags/ItalicAngle), `translator.py::encode/restore/validate_formula_placeholders + validate_style_tags` (fail-closed, cho reorder), `SegmentTooLongError` thay vì cắt câm (`translator.py:31-39,177-182`), `TranslationBatcher` (batch 1500 ký tự/15 segs, delimiter `===LL_SPLIT===`, fallback lẻ), table-match 50% (`rules.py::matching_table_cells(minimum_overlap=0.5)` + `high_level.py:338-379` cluster/should_translate), `TranslationReport reasons` + `translatable_segments`, `should_subset_fonts()=False` + floor vi 1.10em (`rules.py:65-73,118-133`; `high_level.py:82-94`). Nguồn: đọc trực tiếp 4 file local.

## 2. BabelDOC (funstory-ai/BabelDOC)

- IR pipeline: `Parse→DetectScanned→Layout→Table→Paragraph→StylesAndFormulas→AutoTermExtract→ILTranslator→Typesetting→FontMapper→PDFCreater→Subset→Save` với trọng số stage (`babeldoc/.../high_level.py::TRANSLATE_STAGES`, `do_translate/_do_translate_single`). Nguồn: raw `babeldoc/format/pdf/high_level.py`.
- `il_translator` giữ tag: `PROMPT_TEMPLATE` — giữ nguyên cấu trúc/tag/placeholder (`{v1}`, `{name}`, `%s/%d`, `[[...]]`), không dịch trong `<code>`, chỉ dịch text trong tag (`midend/il_translator.py::PROMPT_TEMPLATE`, `get_translate_input/parse_translate_output` với `FormulaPlaceholder/RichTextPlaceholder`, `remove_placeholder` gỡ token ảo LLM). Placeholder LLM là `{vN}` + `<style id>` (`translator/translator.py::OpenAITranslator.get_formular_placeholder`), khác local `<bN></bN>`. Nguồn: raw `il_translator.py`, `translator/translator.py`.
- CJK typesetting (`midend/typesetting.py`): `is_cjk_char` (dải CJK/Hiragana/Katakana/Bopomofo/Hangul + tên `CJK UNIFIED/FULLWIDTH`), `can_break_line` (không bẻ sau `[0-9A-Za-z]` + Latin/Cyrillic/Greek mở rộng), kinboku — `is_hung_punctuation` (treo `，。：？！”)]}…—·/`) + `is_cannot_appear_in_line_end_punctuation` (`“‘「『([{（〔〈《〖`), `line_skip = 1.50 if is_cjk else 1.3`, scale thử từ 1.0→0.1 + mở rộng box, chống đè đoạn. Local chỉ có `line_height zh=1.4/vi=1.2` + floor, không có kinboku/không-bẻ-từ. Nguồn: raw `typesetting.py` (`TypesettingUnit`, `Typesetting._find_optimal_scale_and_layout`, `is_cjk`).
- Glossary + auto-extract: CSV `source,target[,tgt_lng]` (khớp chuẩn hoá `tgt_lng` vs `--lang-out`), bơm bảng vào prompt (`il_translator._build_glossary_block`); auto-extract mặc định bật (`--no-auto-extract-glossary` để tắt, `AutomaticTermExtractor`, `SharedContextCrossSplitPart`). Nguồn: README `Glossary Options`, raw `translation_config.py::SharedContextCrossSplitPart`, `il_translator.py`.
- Cache/QPS: peewee như upstream nhưng **giữ tối đa 50k dòng** (`MAX_CACHE_ROWS=50_000`, `CLEAN_PROBABILITY=0.001`, lock cleanup) (`translator/cache.py::_cleanup`); `RateLimiter` leaky-bucket `monotonic` (`translator/translator.py::RateLimiter`, `_translate_rate_limiter=5`, CLI `--qps` mặc định 4, `pool_max_workers=qps`). Local tương đương thô: Google throttle 0.2s (~5 QPS) + batcher riêng. Nguồn: raw 2 file trên + README `Translation Service Options`.
- Cái nào port được mà không phá `{vN}/<bN>/<s1..3>` + floor vi + no-subset: (a) kinboku read-only (treo dấu + cấm mở đầu dòng) — chỉ chạm typesetting; (b) `can_break_line` cho CJK khi `lang_out∈{zh,ja,ko}`; (c) cleanup cache 50k (độc lập converter); (d) glossary dạng **ngoài** (preferred-table như `preferred_translation` hiện có) — cấm nhét tag mới vào segment mang placeholder; (e) QPS limiter toàn cục thay vì throttle/Google-only. Không port: `<style id>` placeholders, subset-font, shrink-scale cưỡng bức dưới floor vi.

## 3. Repo/fork họ hàng khác (ngắn)

- `PDFMathTranslate/PDFMathTranslate-next` — fork v2/web-ui, xử lý biên + nhất quán liên cột/trang; BabelDOC gọi đây là “self-deployment + WebUI” (README cả hai phía; upstream `--mode precise/--babeldoc`).
- `SUSYUSTC/MathTranslate` — tổ tiên đa luồng được upstream ghi nhận (`README Acknowledgement`); chỉ dịch, không giữ layout PDF.
- `AnythingLLM/Dify/openailiked` — **engine adapter** trong `translator.py`, không phải fork giữ công thức; nhầm lẫn thường gặp.
- Plugin Zotero (`guaguastandup/zotero-pdf2zh`, `zotero-immersivetranslate`) + `MinerU/DocLayout-YOLO/Surya/layoutreader` — công cụ ăn theo/layout (README hai repo). Không thấy fork “giữ công thức cho tiếng khác” đáng kể ngoài `-lo` đa ngôn ngữ của chính upstream.

## 4. So sánh thẳng LayoutLingua vs họ TQ

| Chiều | Mình hơn | Mình thua |
|---|---|---|
| Giữ công thức | validate cân bằng fail-closed + reorder an toàn; `normalize_mt_placeholders` hồi phục tag rách; giữ glyph thiếu/bullet/dọc | thiếu kinboku, không-bẻ-từ CJK, hint placeholder trong prompt |
| Ngôn ngữ/font | vi + 48 NN; floor vi 1.10em đo ink thật; Times/Windows fallback; no-subset tuyệt đối (giữ CID) | CJK typesetting nông (chỉ line-height 1.4 + spacing); font CJK phụ thuộc system/babeldoc asset, không có chiến lược CJK riêng |
| Table | match 50% + cluster từ + `should_translate_table_cell` (dịch cụm, giữ lưới) | upstream/BabelDOC hoặc giữ cả bảng hoặc dịch hết |
| Dịch vụ/batching | `SegmentTooLongError` refuse + `TranslationReport reasons` + batch delimiter có fallback | chỉ 2 engine (google+handoff) vs ~24; batcher tự chế (1500/15) thay QPS limiter + worker-pool chuẩn; cache không cleanup 50k |
| Thuật ngữ | `preferred_translation` vi cho 3 header xoay | không có glossary CSV + auto-extract |

**Khuyến nghị port nhỏ nhất, preservation-safe:** 1) cleanup cache 50k của BabelDOC (`translator/cache.py::_cleanup`: ngưỡng + lock + xác suất) — 0 chạm placeholder; 2) kinboku read-only (2 danh sách dấu + `line_skip` CJK) sau `restore_formula_placeholders`, gate theo `lang_out`; 3) nâng throttle Google-only thành RateLimiter toàn cục (copy `RateLimiter`, mặc định QPS 4–5); 4) glossary ngoài kiểu `preferred_translation` (map tĩnh, chỉ áp segment không placeholder). Mỗi bước kèm 1 regression test hình học/marker/glyph theo AGENTS.md; giữ bất biến: `{vN}↔<bN>` cân bằng, `<s1..3>` cân bằng, floor vi 1.10em, no-subset.
